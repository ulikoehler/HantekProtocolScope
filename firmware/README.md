# DSO-6022BL firmware

`dso6022bl-firmware.hex` is generated by the CMake build. It is copied from
the `Hantek6022API` submodule at
`third_party/Hantek6022API/Firmware/DSO6022BL/dso6022bl-firmware.hex`.

The application uploads it to the oscilloscope's RAM when required; it is not
permanently flashed to the device.
